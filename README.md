# Sejarah Psikologi — Belajar Interaktif

Aplikasi belajar interaktif dalam Bahasa Indonesia tentang sejarah psikologi, disusun ulang dari buku *An Introduction to the History of Psychology* (Hergenhahn & Henley). Berisi cerita per bab, gambar beranimasi, demo yang bisa dicoba, kuis, dan kartu hafalan.

**Buka online:** https://raihankarim19.github.io/belajarpsikologiawal/

Seluruh aplikasi berada dalam satu file `index.html` dan bisa juga dibuka langsung di browser tanpa internet. Progres belajar tersimpan di browser masing-masing pembaca.
